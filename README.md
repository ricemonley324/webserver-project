# Django Pybo WebServer Project

웹서버 컴퓨팅 과제 프로젝트입니다.

## 개발 환경

- Python 3.x
- Django 6.x
- SQLite3
- Bootstrap

---

## 실행 방법

### 1. 패키지 설치

```bash
pip install django
```

---

### 2. 데이터베이스 마이그레이션

```bash
python manage.py makemigrations
python manage.py migrate
```

---

### 3. 서버 실행

```bash
python manage.py runserver
```

---

## 구현 기능

### 신규 기능

4. 게시글 북마크 기능
